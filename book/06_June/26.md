## June 26th BREAK THE PATTERN

***“What reinforcements, then, is it possible to find with which to oppose habit? Why, the contrary habit.”***
—EPICTETUS, DISCOURSES, 1.27.4

Every team has habits that started as good ideas. A daily standup that grew to forty minutes. A rule that every change needs two approvals, now applied to typo fixes. A design doc template so long that people quietly stopped writing design docs.

Epictetus’ remedy for a bad habit is almost too simple: set the contrary habit against it. You don’t argue a habit away. You replace it.

So try the opposite on purpose, for one sprint. If the standup drags, do it in writing for two weeks and see what breaks. If every estimate is padded, start by estimating the smallest possible version. If you always reach for the framework you know, build the next small tool without it. Some of these experiments will fail, and that’s fine. Either way you find out which of your habits are doing real work and which are just familiar. The familiar ones tend to be the ones nobody has questioned in years.
